# Team HTML EA2 Part 1

## Project Description

This project is a TypeScript activity that demonstrates the use of enums, types, objects, functions, and team member information. Each team member is represented using a TypeScript object with their own details and assigned role.

## How to Run the Project

1. Open the project folder in Visual Studio Code.
2. Open the terminal in the project folder.
3. Install the required packages by running:

   npm install

4. Build the TypeScript file by running:

   npm run build

5. Start the project by running:

   npm start

6. Open the localhost link provided by the project in your browser.
7. Open the browser's Developer Tools and go to the Console to view the team member information.

## Technologies Used

TypeScript, JavaScript, HTML, and Node.js.
